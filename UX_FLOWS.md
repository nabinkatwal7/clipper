# Clipper Studio user flows

## Start a clip

Open Home and paste a video URL or upload a file. Choose clip length, count and whether to burn available subtitles. Expand **Advanced project settings** for analysis, branding and export controls. Follow the new project through processing and open a clip for editing or download.

## Resume a project

Open the latest imported project from Home or use **Projects**. Search by title or filter by status. The list shows recently updated projects first. Open a project for status, recoverable errors and output clips.

## Find a tool

Use the eight primary destinations to switch areas. Each destination exposes the implemented tools in the contextual panel. Use the command palette to jump directly to a tool, project or clip. On mobile, the Navigation button opens the same rail and contextual panel.
