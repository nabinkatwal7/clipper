# Clipper Studio user flows

## Start a clip

Open Home and paste a video URL or upload a file. Choose clip length, count and whether to burn available subtitles. Expand **Advanced project settings** for analysis, branding and export controls. Follow the new project through processing and open a clip for editing or download.

## Resume a project

Open the latest imported project from Home or use **Projects**. Search by title or filter by status. The list shows recently updated projects first. Open a project for status, recoverable errors and output clips.

## Find a tool

Use the eight primary destinations to switch areas. Each destination exposes the implemented tools in the contextual panel. Use the command palette to jump directly to a tool, project or clip. On mobile, the Navigation button opens the same rail and contextual panel.

## Clipping engine flows

- **Quick Clip** (Home): choose a source (URL, local file path, existing project) → content type → clip count → length → language → captions → mode → Generate → watch the step list → review clips (play, download, open in editor). Advanced: platform preset, campaign, aspect ratio.
- **Moment finder** (Clipping): pick a source → Find moments → inspect the heatmap tracks and warnings → accept/reject/favourite candidates → render selected. Optional: import chat/replay, Rank with Ollama.
- **Autopilot** (Automation): define trigger and rules → run on a project, or let a trigger start runs → approve selected moments → clips are rendered and checked → review in the library.
- **Campaigns** (Clipping): create rules (or extract from pasted text and review) → check clips → read pass/fail/needs-review.
- **Trend radar** (Clipping): add a creator feed or import a file → check → inspect measured views/age/velocity and missing data.
- **Storage / System health** (Settings): choose a policy → preview cleanup → authorise → delete; view measured resources and choose a hardware profile.
